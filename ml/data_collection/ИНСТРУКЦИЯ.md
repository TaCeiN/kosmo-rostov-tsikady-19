# Сбор большого датасета: что делать руками

Всё в браузере, устанавливать ничего не надо. Файл скрипта — `gee_code_editor.js`.

## Шаг 1. Проба (5 минут)

Открыть https://code.earthengine.google.com → **Scripts → NEW → File**, вставить
скрипт целиком. Поменять две строки вверху:

```js
var N_FIELDS = 5;
var YEARS = [2024];
```

**Run** → вкладка **Tasks** справа → запустить все 5 задач. Через пару минут
в Google Drive появится папка `ndvi_external`.

**Скинуть мне эти файлы.** Проверю, совпадает ли частота наблюдений и диапазон
NDVI с данными организаторов. Если да — гонишь дальше.

## Шаг 2. Замер расхода (10 минут)

```js
var N_FIELDS = 200;
var YEARS = [2024];
var PREVIEW = false;      // иначе редактор зависнет на предпросмотре
```

Запустить, дождаться. Потом зайти в **Earth Engine → Overview** и посмотреть,
сколько EECU-часов съел прогон. На тарифе Community лимит 150 EECU-часов
в месяц. Умножь на 16 (столько лет в полном сборе) и на нужное число партий —
поймёшь, влезаешь ли.

Если не влезаешь — уменьшай `N_FIELDS` или сокращай `YEARS`. Годы 2017–2025
ценнее старых: там есть Sentinel-2, а тестовые контрольные точки на четверть
сидят в 2025-м.

## Шаг 3. Полный сбор партиями

```js
var N_FIELDS = 800;
var PREVIEW = false;      // ОБЯЗАТЕЛЬНО: при большом наборе предпросмотр вешает браузер
var BATCH = 1;            // для второй партии поставить 2, для третьей 3
var YEARS = [2010, 2011, ... , 2025];   // как в скрипте по умолчанию
```

**Run** → **Tasks** → запустить все 65 задач. Считается часами на серверах
Google, браузер можно закрыть.

Партии независимы: `BATCH` меняет и сид выборки полей, и префикс их id
(`EXT1-`, `EXT2-`, ...), так что поля не пересекаются и id не конфликтуют.
Три партии по 800 дадут 2400 полей — в тридцать раз больше, чем у организаторов.

Когда всё доедет: скачать папку `ndvi_external` из Drive, **упаковать в zip**,
скинуть мне.

## Что именно выгружается

| файл | что внутри |
|---|---|
| `ndvi_fields_meta_bN.csv` | паспорт участков: id, ячейка погоды, чистота пашни, однородность |
| `ndvi_s2_ГОД_bN.csv` | Sentinel-2: ndvi, evi, ndwi |
| `ndvi_landsat_ГОД_bN.csv` | Landsat 5/7/8/9 вместе |
| `ndvi_modis_ГОД_bN.csv` | MODIS MOD13Q1 |
| `ndvi_era5_ГОД_bN.csv` | погода **по ячейкам 0.1°**, не по полям |

Про ERA5 отдельно: погода внутри ячейки 10×10 км одинакова для всех полей,
поэтому выгружать её на каждое поле — раздувать архив в десятки раз без единого
нового бита. 800 полей укладываются примерно в 50–80 ячеек. Сшивка обратно
идёт по `cell_id` из паспорта, это делает `merge_external.py`.

Без паспорта погода не пришьётся — **не теряй файлы `fields_meta`**.

## Как отбираются поля

Два фильтра, оба нужны:

1. **Чистота пашни** ≥ 95% по ESA WorldCover — квадрат не должен залезать
   на дорогу, лесополосу или застройку.
2. **Однородность**: разброс NDVI внутри квадрата летом ≤ 0.08. Маска пашни
   не отличает одно поле от двух соседних, а квадрат на границе даёт средний
   NDVI как смесь двух культур — кривую, которой в природе не существует.
   Разброс это ловит: у одного поля он 0.02–0.05, у двух полей 0.2 и выше.

Сторона квадрата 250 м (6 га) — компромисс: достаточно пикселей для усреднения,
но мало шансов сесть на границу.

## Что я сделаю с архивом

1. `merge_external.py` — сведу в схему организаторов: суточная сетка сезона,
   `primary_ndvi` по приоритету S2 → Landsat → MODIS, погода по ячейкам.
2. `validate_external.py` — сверю распределения с данными организаторов.
3. Прогоню валидацию с `--extra` и без, на тех же фолдах и сидах. Упало RMSE —
   данные годные, переобучаю модель и пересобираю сабмит. Выросло — разберусь,
   что в сборе разошлось.

Проверка честная: дособранные поля идут только в обучение, валидация остаётся
на полигонах организаторов. Это гарантировано кодом и проверено тестом.

## Если что-то пойдёт не так

| симптом | причина и что делать |
|---|---|
| `Reprojection output too large` | старая версия скрипта, возьми свежую |
| `User memory limit exceeded` | уменьшить `N_FIELDS` вдвое, собрать двумя партиями |
| `Computation timed out` | сократить `YEARS` до 4–5 лет за запуск |
| страница висит после Run | `PREVIEW = false`: печать статистики считается интерактивно, лимит браузера 5 минут |
| отобралось меньше полей, чем просил | подними множитель кандидатов: `N_FIELDS * 10` → `* 20` |
| пустые CSV по S2 за 2010–2016 | так и должно быть: Sentinel-2 здесь начинается с 2017 |
| мало строк Landsat за 2012 | норма: между Landsat 5 и 8 работал только Landsat 7 |
