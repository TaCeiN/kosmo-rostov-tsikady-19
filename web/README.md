# NDVI Field Analysis Web Application

Веб-приложение для интерактивного анализа временных рядов вегетационного индекса NDVI сельскохозяйственных полей Ростовской области, детекции аномалий развития культур и классификации их причин.

---

## Стек технологий

- **Фреймворк**: React 18 + Vite 5 + TypeScript (строгий режим `strict: true`, `noUncheckedIndexedAccess: true`, zero `any`)
- **Стилизация**: Tailwind CSS + Lucide React (иконки)
- **Картография**: Leaflet 1.9 + Leaflet Draw (тайлы OpenStreetMap, контур Ростовской области, рисование полигонов и прямоугольников)
- **Графики**: Apache ECharts 5 (`echarts-for-react`) — климатический коридор нормы, сглаженный ряд, наблюдения (scatter), маркеры аномалий, погодные ряды, синхронизация тултипов и зума
- **Управление состоянием и кэширование**: TanStack Query v5 + Zustand
- **Парсинг CSV**: PapaParse с веб-воркером (`worker: true`)
- **Тестирование**: Vitest + jsdom

## Настройка окружения

Создайте файл `.env` в папке `web/` (скопировав из `.env.example`):

```bash
cp .env.example .env
```

Параметры:
- `VITE_API_URL` — URL FastAPI бэкенда (по умолчанию `http://localhost:8000`). Если бэкенд выключен или недоступен, приложение автоматически сигнализирует об этом в шапке и предлагает перейти в режим `/demo`, функционирующий полностью автономно на статических данных.

## Установка и запуск

### 1. Установка зависимостей
```bash
cd web
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение запустится по адресу: `http://localhost:5173/`.

### 3. Сборка для продакшена
```bash
npm run build
```
Собранные оптимизированные файлы помещаются в каталог `web/dist/`.

### 4. Предпросмотр сборки
```bash
npm run preview
```

### 5. Запуск тестов
```bash
npm test
```
Запускает набор из 24 модульных тестов Vitest (jsdom), проверяющих логику адаптеров, сегментацию дат, расчет площади и валидацию координат.

## Реализованные экраны и ключевые возможности

1. **Интерактивный анализ (`/`)**:
   - Leaflet-карта с подсветкой границ Ростовской области.
   - Рисование произвольного полигона или прямоугольника с мгновенной валидацией координат и точным расчетом площади в гектарах по геодезической трапецеидальной формуле (полное совпадение с бэкендом).
   - Быстрые пресеты полей из метаданных `/meta`.
   - Асинхронный пайплайн с двухэтапным чеклистом ("Сбор данных" -> "Обработка и детекция"), расчетом оставшегося времени, счетчиками наблюдений и фактами о спутниках Sentinel-2 и Landsat.
   - Обработка сценария потери задачи (HTTP 404) с возможностью перезапуска.

2. **График NDVI и карточки аномалий**:
   - Строгая сегментация временного ряда: линии прерываются при разрыве дельта t > 1 дня и в зимний период (30 октября — 1 апреля), исключая ложные линейные интерполяции через зиму.
   - Диапазон оси Y фиксирован в пределах `[-0.2, 1.0]`.
   - Наблюдения `ndvi_obs` отображаются исключительно точечной диаграммой (scatter).
   - Подсветка зон аномалий (`markArea`), климатический коридор нормы (±1.5 сигма), сглаженный ряд `ndvi_smooth`.
   - Карточки периодов аномалий с расчетом человекочитаемой глубины проседания (в абсолютном значении NDVI, процентах от нормы и сигмах z).
   - Сортировка по минимальному z, фильтры по годам, критичности и причинам.

3. **Демо-режим (`/demo`)**:
   - Работает на 100% автономно на статических данных (`data/series`, `data/anomalies.json`, `data/meta.json`) без обращения к бэкенду и без Leaflet-карты (координаты анонимизированы).
   - Сводные карточки по 78 полигонам, фильтрация по культуре, сортировка по площади и числу аномалий.
   - Сравнение двух полей на одном графике с совмещением климатических норм и аномалий.

4. **Метрики качества (`/metrics`)**:
   - Главный баннер качества модели (F1: 0.816, точность: 85.9%, полнота: 77.7%).
   - Таблица истинности (Confusion Matrix: TP 599, FP 98, FN 172, TN 10 491).
   - Графики качества детекции: зависимость от величины пропусков (gap size), фенологической фазы, культуры и группы критичности.
   - Аналитические выводы на русском языке с рекомендациями для агрономов.

5. **Пакетный инференс (`/predict`)**:
   - Загрузка пользовательских CSV файлов через Drag-and-Drop.
   - Быстрый разбор в веб-воркере (`PapaParse`), предпросмотр первых 20 строк.
   - Интерактивный маппинг колонок полигона, даты, NDVI и метеоданных.
   - Мягкая валидация структуры без блокировки пользователя.
   - Синхронная отправка на инференс и визуализация результатов через компонент анализа.

6. **Экспорт данных**:
   - Экспорт графиков в PNG высокого разрешения (2x retina canvas).
   - Экспорт временного ряда в CSV с префиксом UTF-8 BOM (`\uFEFF`) и разделителем `;` для корректного открытия в русском Microsoft Excel.
   - Экспорт реестра аномалий поля в CSV (BOM + `;`).
   - Экспорт полных исходных результатов в JSON.
