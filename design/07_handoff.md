# Контракт «дизайн ↔ разработка»

Дизайн делается в Stitch, код пишут дев-агенты по `docs/06-frontend/`.
Эти два процесса идут **параллельно и независимо** — значит, они сойдутся
только если заранее договориться, что именно является общим.

## Кто в чём главный

| Вопрос | Источник истины |
|---|---|
| Какие экраны существуют | `10-design/04-screens-states.md` |
| Как экран выглядит | Макет Stitch + `10-design/01-design-tokens.md` |
| Что на экране написано | `10-design/05-copy-ru.md` — **дословно** |
| Какие данные на экране | `03-architecture/api-contract.md` |
| Как экран себя ведёт | `06-frontend/*.md` |
| Как считаются числа | `05-ml/*.md` |

**При расхождении макета и спеки прав документ спеки, макет правится.**
Единственное исключение — чистая визуальная подача (отступы, размеры,
оформление): там прав макет.

## Что дев-агент обязан взять из макета

Ровно четыре вещи:

1. **Токены** — палитра, типографика, радиусы, тени из `01-design-tokens.md`.
   Кладутся в CSS-переменные с **теми же именами**, что в документе.
2. **Композиция** — ширина панелей, высоты блоков, отступы. Из Figma-экспорта.
3. **Состав экрана** — какие блоки есть и в каком порядке.
4. **Состояния** — что показывать, когда данных нет, часть источников упала,
   истории мало, покрытие низкое.

## Чего дев-агент из макета брать не должен

- **HTML/CSS, который экспортирует Stitch.** Это одноразовая разметка под
  картинку: нет состояний, нет доступности, нет реальных компонентов,
  всё абсолютным позиционированием. В репозиторий не переносится.
- **Заглушки карты и графика.** В продукте это MapLibre и uPlot.
- **Числа с макета.** «0,543», «96,2 га», «47 контуров» — это демо-данные
  для картинки, а не константы.
- **Иконки как картинки.** Берётся один линейный набор, ставится как SVG.

## Поведение, которого нет в макете

Stitch не рисует анимации и микровзаимодействия, поэтому всё это существует
только текстом. Дев-агент реализует по этому списку, дизайнер не рисует.

| Взаимодействие | Поведение |
|---|---|
| Наведение на кнопку | Затемнение фона на 6 %, без сдвига и без тени |
| Нажатие | Затемнение на 12 %, без «вдавливания» |
| Фокус с клавиатуры | Кольцо 2 px `--brand`, отступ 2 px. Обязательно, не убирать |
| Наведение на точку графика | Кроссхэйр по вертикали + тултип у курсора, маркер увеличивается до 10 px |
| Наведение на карточку аномалии | Подсветка соответствующей полосы на графике |
| Клик по карточке аномалии | График зумится на период, карточка раскрывается |
| Наведение на полигон в списке | Подсветка контура на карте |
| Появление плашки | Без анимации; плашка просто есть при загрузке экрана |
| Прогресс сбора | Обновление раз в секунду опросом `GET /api/jobs/{id}` |
| Скелетоны | Статичные, без «переливания» — оно отвлекает и стоит кадров |
| Тултип карты | Появляется по клику, а не по наведению: на тач-устройствах ховера нет |

Переходы — 120 мс, `ease-out`, только `opacity` и `background-color`.
Ничего не двигается и не масштабируется: на демо через проектор
анимации выглядят как лаги.

## Доступность — минимум, который проверяют

- Контраст текста не ниже 4,5:1. Прямо в критерии «Ясность».
- Все интерактивные элементы достижимы с клавиатуры, фокус видим.
- Статус — цвет **плюс** иконка **плюс** слово. Нигде не цвет в одиночку.
- У иконок-кнопок есть `aria-label` на русском.
- Ничего меньше 12 px.
- График имеет альтернативу: кнопка «Экспорт CSV» — это и есть табличное
  представление тех же данных.

## Порядок синхронизации

```
1. Дизайнер финализирует стиль-блок на S-03 → фиксирует 02-style-block.md
2. Дизайнер выкладывает PNG в docs/screenshots/ с именами <ID>-<имя>.png
3. Дев-агент UI-01 забирает токены из 01-design-tokens.md
   (НЕ из макета — из документа: он и есть контракт)
4. Дев-агенты UI-02…UI-05 сверяют композицию по PNG
5. Расхождение → правится тот, кто отступил от документа
```

Дев-агенту **не нужно ждать** макетов, чтобы начать: токены, тексты и состав
экранов зафиксированы документами, а они уже готовы. Макет уточняет подачу,
но не блокирует разработку. Это и есть смысл того, чтобы держать контракт
в текстовых файлах, а не в картинке.
