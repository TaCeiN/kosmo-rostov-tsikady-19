# Дизайн-токены

Единый источник истины по цвету, типографике и размерам. Дизайнер вставляет их
в промпт (`02-style-block.md`), дев-агенты кладут в CSS-переменные.
**Имена токенов одинаковые с обеих сторон** — это и есть контракт.

## Тема

Одна тема — светлая. Причины: демо идёт через проектор, где тёмный фон
съедает контраст карты и графиков; и каждая дополнительная тема — это ×2
генераций в Stitch при лимите 50 Experimental в месяц. Тёмная тема — только
если останется время, и тогда её значения берутся из колонки «Dark» ниже.

## Палитра

### Акцент

| Токен | Light | Dark | Назначение |
|---|---|---|---|
| `--brand` | `#2a78d6` | `#3987e5` | Основные кнопки, выделение, активные состояния |
| `--brand-weak` | `#cde2fb` | `#184f95` | Заливка выбранного полигона, фон подсказок |

### Статусы аномалий

Фиксированные, не темизируются. Всегда идут **с иконкой и подписью** — цвет
никогда не несёт смысл в одиночку.

| Токен | Hex | Значение в продукте |
|---|---|---|
| `--status-good` | `#0ca30c` | Штатное развитие |
| `--status-warning` | `#fab219` | Угнетение биомассы (−2 ≤ z < −1) |
| `--status-critical` | `#d03b3b` | Критическая аномалия (z < −2) |
| `--status-serious` | `#ec835a` | Данные ненадёжны / низкое покрытие |

### Источники спутниковых данных

Три категориальных слота. **Форма маркера дублирует цвет** — так источник
читается и в оттенках серого, и при дальтонизме.

| Источник | Цвет Light | Цвет Dark | Форма маркера |
|---|---|---|---|
| Sentinel-2 | `#2a78d6` | `#3987e5` | круг |
| Landsat 8/9 | `#eb6834` | `#d95926` | квадрат |
| MODIS | `#1baf7a` | `#199e70` | треугольник |

Палитра прогнана валидатором на всех парах в обоих режимах:

```
light: CVD ΔE 9.2 (минимум по всем парам), обычное зрение ΔE 24.0 — PASS
dark:  CVD ΔE 9.4, обычное зрение ΔE 20.9 — PASS
```

Одно замечание из проверки: на светлом фоне `#1baf7a` (MODIS) даёт контраст
2.74:1, ниже порога 3:1. Поэтому **легенда с подписями обязательна**, а в
тултипе источник называется словом. Без этого MODIS-маркеры будут теряться.

### Хитмап аномалий по региону

Расходящаяся шкала с нейтральной серединой — у z-score есть естественный ноль.

```
z ≤ −3   #d03b3b   критично
z = −2   #e08a70
z = −1   #f0c8b4
z =  0   #f0efec   нейтральная середина (серый, НЕ цвет)
z = +1   #9ec5f4
z ≥ +2   #2a78d6   выше нормы
```

Радужную шкалу не используем ни при каких обстоятельствах — она создаёт
границы там, где их нет в данных.

## Типографика

Системный шрифт без засечек — грузится мгновенно и не ломается офлайн:

```
font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
```

| Роль | Размер / высота строки | Начертание |
|---|---|---|
| H1 — название экрана | 24 / 32 | 600 |
| H2 — заголовок панели | 18 / 26 | 600 |
| H3 — подзаголовок | 15 / 22 | 600 |
| Body — основной текст | 14 / 21 | 400 |
| Small — подписи, метаданные | 13 / 18 | 400 |
| Caption — оси графика, сноски | 12 / 16 | 400 |
| Число-герой (KPI) | 32 / 38 | 600 |

**Меньше 12 px не бывает нигде.** На проекторе это уже нечитаемо, а «Ясность»
презентации — прямые 5 баллов.

Числа в таблицах и на осях — `font-variant-numeric: tabular-nums`, чтобы
столбцы не плясали. Крупные одиночные числа — обычные пропорциональные.

## Сетка и размеры

```
Базовый шаг:      4 px. Все отступы кратны четырём.
Ширина макета:    1440 × 900 (проектор), проверить на 1280 × 800
Левая панель:     320 px, фиксированная
Правая колонка:   остальное
Верхняя панель:   56 px
Карта:            занимает верхние ~55% правой колонки
График:           под картой, высота 260 px
Лента аномалий:   под графиком, высота 180 px, скролл внутри
Радиус скругления: 8 px карточки, 6 px кнопки и поля, 4 px чипы
Тень:             одна, мягкая — 0 1px 2px rgba(11,11,11,0.06)
```

Тень ровно одна на весь интерфейс. Несколько уровней теней — самый быстрый
способ получить «сделано на коленке».

## Компоненты

Список того, что вообще существует в интерфейсе. Ничего сверх этого списка
дизайнер не рисует, дев-агент не изобретает.

| Компонент | Варианты | Где встречается |
|---|---|---|
| Кнопка | primary, secondary, ghost, danger; обычная / disabled | Везде |
| Поле ввода | обычное, с иконкой поиска, с ошибкой | Поиск региона, имя полигона |
| Чип | обычный, выбранный, с крестиком | Фильтры, культура, источники |
| Карточка полигона | обычная, выбранная, в обработке | Левая панель |
| Плашка-уведомление | info, warning, error, success | Ошибки источников, покрытие |
| Строка прогресса | этап: ожидание / идёт / готово / ошибка | Панель сбора данных |
| Карточка аномалии | moderate, critical, «данные ненадёжны» | Лента аномалий |
| Легенда графика | горизонтальная, с формами маркеров | Под графиком |
| Тултип | точка наблюдения / восстановленная точка | График |
| Пустое состояние | иллюстрация-заглушка + текст + действие | Все панели |
| Скелетон загрузки | прямоугольники на месте контента | Все панели |
| Индикатор источников | «5 из 6 доступны», с раскрытием | Верхняя панель |

## Иконки

Один набор, линейные, толщина 1.5 px, размер 16 и 20 px. Подойдёт любой
открытый (Lucide, Feather, Material Symbols Outlined) — важно, чтобы **набор
был один**. Смесь наборов заметна мгновенно и читается как неряшливость.

Обязательный минимум: поиск, карта, полигон, карандаш, корзина, скачать,
предупреждение (треугольник), критично (восклицательный знак в круге),
информация, галочка, крестик, обновить, слои, календарь, шестерёнка.
